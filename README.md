# 교육과정 시수 자동 맞춤

초등학교 교육과정 구성표(한글 `.hwpx`)를 열면 주별·월별 수업일수와 시수, 학년별 교과·창체 시수를 자동으로 계산해 **원본 서식 그대로 숫자만 바꾼 파일**로 내려받는 도구입니다.

**사용하기:** https://hryoon0.github.io/cu-form/

## 쓰는 법
1. «한글 파일(.hwpx) 열기»로 구성표를 엽니다. `.hwp`는 한글에서 «다른 이름으로 저장 → HWPX»로 바꿉니다.
2. «학사일정»에 휴업일·방학을, «행사 시수 조정»에 시업식·방학식처럼 교시가 달라지는 날을 넣습니다.
3. «교과·창체 시수»에서 달력 시수에 맞게 과목 시수를 고칩니다(«남은 시수 자동 배분» 사용 가능).
4. «한글 파일로 내려받기».

## 자료는 어디에 저장되나
- 한글 파일은 **브라우저 안에서만** 읽고 고칩니다. 어떤 서버로도 보내지 않습니다.
- 학사일정·행사 설정은 이 브라우저에만 저장됩니다(학년도+파일 이름별). 다른 PC로 옮길 때는 «설정 백업(JSON)» → «설정 불러오기».

## 편성 기준 검사
연간 수업일수 190일, 1일 수업 시수, 교과(군)·창체 ±20%, 체육·예술 감축 불가, 학년군 최소 시수, 학교자율시간(학년 총 시수÷34, 17차시 이상, 한 학기 2개 이내, 3~4·5~6학년군 필수).
근거: 경상남도교육청 「2026학년도 경상남도 초등학교 교육과정 설계·운영 도움자료」, 「2025. 초등학교 학교자율시간 도움자료」.

## 한계
- 표 제목·배치로 표를 찾으므로 양식이 크게 다른 구성표는 읽지 못할 수 있습니다.
- 주 수가 파일의 행 수와 다르면 그 학기 주별 표는 반영하지 않습니다(한글에서 행을 먼저 맞추세요).
- 학사일정 표, 날짜 칸의 동그라미·색은 자동으로 바꾸지 않습니다.

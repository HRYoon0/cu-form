# 교육과정 시수 자동 맞춤

초등학교 교육과정 수업일수·시수표를 자동으로 맞추는 도구입니다. 두 가지로 쓸 수 있습니다.

- **새로 만들기**: 학년도를 고르면 학기·방학·공휴일·요일별 시수·식 행사, 2022 개정 교육과정 기준 시수가 기본으로 채워집니다. 고친 뒤 학사일정부터 주간 배당까지 모든 표가 담긴 **새 한글 파일**로 내려받습니다.
- **기존 한글 파일에 채워 넣기**: 학교에서 쓰던 구성표(`.hwpx`)를 열면 원본 서식 그대로 숫자만 바꾼 파일로 내려받습니다.

**사용하기:** https://hryoon0.github.io/cu-form/

## 쓰는 법
1. 처음 화면에서 «새로 만들기»(학년도 선택) 또는 «한글 파일(.hwpx) 열기»를 고릅니다. `.hwp`는 한글에서 «다른 이름으로 저장 → HWPX»로 바꿉니다.
2. «학사일정»에 휴업일·방학을, «행사 시수 조정»에 시업식·방학식처럼 교시가 달라지는 날을 넣습니다.
3. «교과·창체 시수»에서 달력 시수에 맞게 과목 시수를 고칩니다(«남은 시수 자동 배분» 사용 가능). 새로 만들기에서는 학교자율시간 과목도 여기서 추가합니다.
4. «한글 파일 만들기»(새로 만들기) 또는 «한글 파일로 내려받기»(채워 넣기).

## 자료는 어디에 저장되나
- 한글 파일은 **브라우저 안에서만** 읽고 고칩니다. 어떤 서버로도 보내지 않습니다.
- 입력한 구성은 이 브라우저에만 저장됩니다(새로 만들기는 학년도별, 채워 넣기는 학년도+파일 이름별). 다른 PC로 옮길 때는 «설정 백업(JSON)» → «설정 불러오기».

## 편성 기준 검사
연간 수업일수 190일, 1일 수업 시수, 교과(군)·창체 ±20%, 체육·예술 감축 불가, 학년군 최소 시수, 학교자율시간(학년 총 시수÷34, 17차시 이상, 한 학기 2개 이내, 3~4·5~6학년군 필수).
근거: 경상남도교육청 「2026학년도 경상남도 초등학교 교육과정 설계·운영 도움자료」, 「2025. 초등학교 학교자율시간 도움자료」.

## 기본값의 출처
- 공휴일: 2026학년도는 경남 학사일정, 2027학년도는 공휴일표(대체공휴일 포함). 그 밖의 해는 날짜가 고정된 공휴일만 들어가니 설·추석·부처님오신날을 넣어야 합니다.
- 기준 시수: 2022 개정 교육과정 학년군별 시간 배당(±20% 범위 자동 계산). 1·2학년 한 해 기준(국어 244/238 등)은 흔히 쓰는 값이라 학교에 맞게 고칩니다.
- 식 행사 교시(시업식 4·5교시 등)는 예시값입니다.

## 개발
- `core.js` 계산·HWPX 읽기/쓰기, `blank.js` 기본값·새 문서 조립, `skeleton.js` 한글 문서 골격(자동 생성, `tools/build_skeleton.py`).

## 한계
- (채워 넣기) 표 제목·배치로 표를 찾으므로 양식이 크게 다른 구성표는 읽지 못할 수 있습니다. 이럴 때는 새로 만들기를 쓰세요.
- (채워 넣기) 주 수가 파일의 행 수와 다르면 그 학기 주별 표는 반영하지 않습니다(한글에서 행을 먼저 맞추세요). 새로 만들기는 주 수에 맞춰 표를 새로 짭니다.
- 학사일정 표, 날짜 칸의 동그라미·색은 자동으로 바꾸지 않습니다.
